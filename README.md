# Katana60 Pro

KiCad project for the Katana60 Pro: a 60% keyboard PCB with the symmetrical staggered layout of the original Katana60, now with hot-swap sockets.

* Hot-swap MX sockets
* USB-C
* ATmega32U4
* Split or 7u spacebar
* Compatible with 60% cases

Looking for the version with a trackpoint? That one has moved to its own repository: [katana60-pro-trackpoint](https://github.com/rominronin/katana60-pro-trackpoint).

The matching FR4 plate lives in [katana60-pro-plate](https://github.com/rominronin/katana60-pro-plate).
